## About This Repository

This repo holds the source for the official book site — a single, hand-built landing page with one job: help readers find *The Heart of Joseph* and choose an edition. No framework, no build step, no dependencies. Just HTML and CSS, deployed straight to GitHub Pages.

## The Book

> *The Heart of Joseph* is a revealing portrait — intimate and documented — of the heart, character, and soul of Joseph Smith. Across five sections and twenty-three chapters, readers discover not simply what Joseph taught, but who he was — and how the way he lived became its own kind of teaching.

The book is built on two complementary voices: firsthand accounts from those who knew Joseph, and Joseph's own words — including every surviving letter he wrote to his wife Emma.

## Built With

- Semantic HTML5 and hand-written CSS — no framework, no preprocessor, no build tooling
- [Cormorant Garamond & Lora](https://fonts.google.com) via Google Fonts
- Hosted on [GitHub Pages](https://pages.github.com/), served from a custom domain

## Running Locally

There's nothing to install. Clone the repo and open the file:

```bash
git clone https://github.com/robertbthompson/robertbthompson.github.io.git
cd robertbthompson.github.io
open index.html
```
