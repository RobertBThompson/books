## About This Repository

This repo holds the source for the official STT Press site — a single, hand-built landing page with one job: help readers find STT Press titles and choose an edition. It leads with *The Heart of Joseph*, the flagship title, and also features *Jesus the Christ* alongside a running list of titles in production. No framework, no build step, no dependencies. Just HTML and CSS, deployed straight to GitHub Pages.

## The Books

### The Heart of Joseph

> *The Heart of Joseph* is a revealing portrait — intimate and documented — of the heart, character, and soul of Joseph Smith. Across five sections and twenty-three chapters, readers discover not simply what Joseph taught, but who he was — and how the way he lived became its own kind of teaching.

The book is built on two complementary voices: firsthand accounts from those who knew Joseph, and Joseph's own words — including every surviving letter he wrote to his wife Emma.

Hardcover and paperback editions are available for wholesale ordering to any bookstore or library through [IngramSpark](https://www.ingramspark.com).

### Jesus the Christ (1915 edition, restored)

A faithful return to James E. Talmage's original 1915 wording, brought into a large hardback edition built for the way readers actually study it today.

- **Large hardback** — a substantial 7×10 edition, rare in today's market
- **Updated format & index** — the original 1915 text reformatted for readability, with a rebuilt, easier-to-navigate index
- **Throwback cover** — a cloth-bound design drawn from one of the book's original early prints

Currently available in hardcover on Amazon. Additional formats and retailers will join The Heart of Joseph's outlets over time.

## Built With

- Semantic HTML5 and hand-written CSS — no framework, no preprocessor, no build tooling
- [Cormorant Garamond & Lora](https://fonts.google.com) via Google Fonts
- Hosted on [GitHub Pages](https://pages.github.com/), served from a custom domain

## Running Locally

There's nothing to install. Clone the repo and open the file:

```bash
git clone https://github.com/RobertBThompson/books.git
cd books
open index.html
```
