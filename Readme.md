## About This Repository

This repo holds the source for the official STT Press site — a single, hand-built landing page with one job: help readers find STT Press titles and choose an edition. It leads with *The Heart of Joseph*, the flagship title, and also features *Jesus the Christ (Annotated)* alongside a running list of titles in production. No framework, no build step, no dependencies. Just HTML and CSS, deployed straight to GitHub Pages.

## The Books

### The Heart of Joseph

> *The Heart of Joseph* is a revealing portrait — intimate and documented — of the heart, character, and soul of Joseph Smith. Across five sections and twenty-three chapters, readers discover not simply what Joseph taught, but who he was — and how the way he lived became its own kind of teaching.

The book is built on two complementary voices: firsthand accounts from those who knew Joseph, and Joseph's own words — including every surviving letter he wrote to his wife Emma.

### Jesus the Christ (Annotated): Simple and Clear Wording

The newest release from STT Press — the message of James E. Talmage's classic, brought into simple, clear wording and annotated for today's reader.

- **Simple, clear wording** — the classic text reworded for easy, modern reading
- **Annotated** — notes throughout to guide and clarify the reading
- **A companion volume** — pairs naturally with the original 1915 text, also part of the STT Press collection

Purchase links will be added as retailers go live.

### Also in the collection: Jesus the Christ (1915 edition, restored)

A faithful return to James E. Talmage's original 1915 wording, brought into a large hardback edition — a large 7×10 format with an updated, easier-to-navigate index and a throwback cloth-bound cover. Available now in hardcover on Amazon.

## Running Locally

There's nothing to install. Clone the repo and open the file:

```bash
git clone https://github.com/RobertBThompson/books.git
cd books
open index.html
```
